# Laurier STEM Publishing Society

Official website for the **Laurier STEM Publishing Society (LSPS)** — a student organization at Wilfrid Laurier University (Waterloo campus) made up of students passionate about STEM and publishing.

Live site: https://laurierstempublishingsociety.github.io

## About

LSPS fosters a welcoming environment for STEM students interested in publishing. We host monthly discussion portals, bring in guest speakers from the writing and publishing industry, and collaborate with other student clubs to help members pursue their publishing goals.

## Project Structure

```
.
├── index.html     # Home page (hero, about, mission, events)
├── team.html      # Our Team page
├── global.css     # Shared styles
├── global.js      # Shared scripts
└── images/        # Image assets
```

Built as a static site with plain HTML, CSS, and JavaScript. Hosted via GitHub Pages.

## Local Development

Clone the repo and open `index.html` in a browser:

```bash
git clone https://github.com/LaurierStemPublishingSociety/LaurierStemPublishingSociety.github.io.git
cd LaurierStemPublishingSociety.github.io
```

Or serve it locally with any static server, e.g.:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

The site is deployed automatically through GitHub Pages from the default branch. Pushes to the main branch update the live site.
